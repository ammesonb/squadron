# Variables

Variables separate deployment-specific values from reviewable HCL configuration. HCL declares the name, default, and whether a value is sensitive. Command Center owns the stored value.

## Declare variables in HCL

```hcl
variable "database_password" {
  secret = true
}

variable "environment" {
  default = "development"
}
```

Variable names use lowercase letters, digits, and underscores and cannot start with a digit.

## Set workspace values

Open the workspace's **Settings** page in Command Center and add or update a variable. Managers and administrators can manage values. Secret values are masked by default. A manager or administrator can explicitly reveal a current value; every reveal is recorded in the audit log and the response is not cached by the browser.

Command Center encrypts every value before writing it to its database. A connected workspace runner receives the workspace's complete value set over its authenticated connection and keeps it only in process memory. A disconnected runner receives the current set when it reconnects.

## Reference variables

```hcl
agent "assistant" {
  personality = "Assistant for ${vars.environment}"
}

mcp "internal" {
  url = "https://tools.${vars.environment}.example.com/mcp"
}
```

## Resolution order

1. The workspace value stored in Command Center.
2. The `default` from a matching `variable` block.
3. An empty string when a declared variable has neither a stored value nor a default.
4. An HCL evaluation error when an undeclared and unset variable is referenced.

## Security boundary

- The Command Center database is the system of record.
- Values are encrypted with a key derived from the deployment master key.
- Encryption binds a value to both its workspace and variable name.
- The worker does not persist workspace variable values.
- Mark sensitive declarations with `secret = true` so Command Center masks them in operator views until an authorized operator explicitly reveals them.

Model, MCP, and plugin authorization use their own connection-auth models; they are not workspace variables.
