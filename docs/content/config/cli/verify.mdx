# squadron verify

Validate an HCL configuration directory.

## Usage

```bash
squadron verify <path>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `path` | Path to the configuration directory |

## Example

```bash
squadron verify ./my-config
```

## Output

On success:

```
Configuration is valid!
Found 2 model provider(s)
  - openai (models: [gpt_5 gpt_5_mini])
  - anthropic (models: [claude_sonnet_4_6])
Found 1 variable(s)
  - environment (set)
Found 1 agent(s)
  - assistant (tools: [builtins.http.get])
Found 1 mission(s)
  - data_pipeline (commander: claude_sonnet_4, agents: [assistant], tasks: 3)
```

On error:

```
Error: agent 'assistant': model 'invalid_model' not found
```

## What Gets Validated

- HCL syntax
- Variable references (`vars.name`)
- Model references (`models.provider.model_key`)
- Tool references (`builtins.namespace.tool`, `plugins.namespace.tool`, `tools.name`)
- Mission task dependencies (no cycles)
- Dataset schemas and bindings
- Plugin install (download + checksum verify)
- Gateway install (download + checksum verify; `version = "local"` requires the binary to already exist at the cached path)
