# Workspace Connection

> **Deprecated configuration block:** Current versions of `squadron engage` obtain the product URL and worker credential from the local connection profile. They do not use `command_center` HCL for the active worker connection.

The `command_center` block remains parseable for compatibility with older projects:

```hcl
command_center {
  url                = "wss://squadron.example.com/ws"
  instance_name      = "production"
  auto_reconnect     = true
  reconnect_interval = 10
}
```

Do not put a worker credential in HCL. The credential is a machine secret and is deliberately stored outside source-controlled configuration.

## Current connection setup

Run:

```bash
squadron engage
```

On the first interactive run for a project, Squadron asks for:

- The WebSocket URL shown in the workspace's connection details
- The workspace runner credential

It saves those values to `.squadron/command-center.json` with owner-only file permissions. Subsequent background and system-service starts reuse that profile.

Each workspace has one worker credential and one connected Squadron worker. Use separate project directories and connection profiles for separate workspaces.

## Legacy fields

| Field | Type | Description |
|---|---|---|
| `url` | string | WebSocket URL used by older worker versions. |
| `instance_name` | string | Legacy worker display name. Current shared deployments derive the workspace identity from the credential. |
| `auto_reconnect` | bool | Legacy reconnect switch. Current Engage workers reconnect continuously. |
| `reconnect_interval` | number | Legacy retry interval in seconds. |
