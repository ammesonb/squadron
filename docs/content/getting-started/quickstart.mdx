# Quick Start

Create a Squadron project, connect its worker, and run a mission.

## 1. Create a project directory

```bash
mkdir my-squadron
cd my-squadron
```

## 2. Create a workspace

In the Squadron product, create a workspace and open its connection details. Keep the WebSocket URL and runner credential ready. Each credential enrolls one worker into one workspace.

## 3. Engage Squadron

```bash
squadron engage
```

On a fresh interactive project, the wizard:

- Selects an LLM provider
- Optionally generates a starter mission
- Prompts for the workspace WebSocket URL and runner credential
- Starts the worker and installs its user-level system service

The machine credential is saved under `.squadron/`, not in HCL.
After the worker connects, add the provider key from the workspace's **Settings** page. Command Center stores workspace values in its database and delivers them to the worker in memory.

## 4. Run the mission

Open the connected workspace in the Squadron product, choose a mission, provide its inputs, and select an eligible execution identity.

You can also run locally from the terminal:

```bash
squadron mission hn_research
```

## 5. Stop the worker

From the same project directory:

```bash
squadron disengage
```
